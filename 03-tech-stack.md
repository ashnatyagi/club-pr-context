## Notes / gotchas
- The workflow naming convention confirmed in use: **"Club PR - Flow [Letter] - [Purpose]"** (e.g. "Club PR - Flow B - Reactive Reel Generation").
- Rows get picked up by Flow B when `status = 'tagged' AND fast_track = 'Y'`, or `status = 'needs_review'`. **Flow A** is what sets `status`/`fast_track`/`vibe_tag`/`overlay_zone` on new rows.
- QC is a two-stage gate: automated (Groq Vision) first, human (Telegram) second — a failed AI QC does not block the item, it routes to a person instead of silently dying.
- The **Instagram access token expires** and Meta Graph API versions age out (currently v24.0) — these are the most likely things to silently break Flow D. Watch for it.
- One Google Sheet is the whole database — a schema change (renaming/removing a column) can break multiple flows at once. Treat sheet columns as a shared contract (see `05-conventions.md`).
- n8n Overview showed ~0.6% failure rate over ~12.7k executions as of 2026-09-16 — healthy, but check the Executions tab when something looks off.
- VPS-specific gotchas (restart schedule, backup/restore plan, API rate limits) not yet documented — tracked in `09-open-questions.md`.
- **Groq vision model can silently lose account access** without a deprecation notice — happened to `qwen/qwen3.6-27b` on 2026-09-17, breaking all 3 vision calls at once (they share one credential + model name). If it happens again, check `console.groq.com/docs/models` for the current documented vision model(s) and update all 3 nodes together (Flow A image tagging, Flow A `Groq Video Tag`, Flow B `Groq Vision QC Check`).
- **Telegram webhooks on this instance can go stale silently** — Flow A went 24+ hours with zero executions on 2026-09-16/17 with no error or alert. Fix is unpublish + republish the workflow (forces n8n to re-register the webhook with Telegram's Bot API).
- **Groq rate limit on this account: 1000 output tokens per minute (OTPM), on-demand tier.** A request whose `max_tokens` exceeds it is rejected outright with `Request too large ... Limit 1000, Requested N` — it is not throttled, it fails. Flow A's `Groq Video Tag` runs at `max_tokens: 800` for this reason. Check this before raising `max_tokens` on any Groq node.
- **In n8n HTTP Request nodes, a JSON body containing `{{ ... }}` must have the body field set to Expression mode** (the small Fixed | Expression toggle above the field). In Fixed mode the expression is transmitted as literal text — with an image URL this shows up as Groq replying `unsupported protocol: (only http and https are allowed)`, which does not obviously point at the real cause.
- **Verifying a fix on this n8n instance:** use a fresh trigger, or copy the node into a throwaway workflow and run it there. The Executions "Retry" button replays the original execution's workflow snapshot and will keep reproducing bugs that are already fixed.
